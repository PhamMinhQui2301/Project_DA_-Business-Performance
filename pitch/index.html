Star Schema

Key Design Decisions
✅ IsSuccess = TRUE()
BIT column → Boolean filter, không dùng = 1
✅ DISTINCTCOUNT Orders
Grain = line item, cần distinct để đếm đơn hàng
✅ FullDate làm Date Table
DateKey là INT → phải dùng FullDate để Mark
✅ Tắt Auto Date/Time
LocalDateTable conflict với marked Date Table
✅ ABS(PlatformFee)
Tiki lưu fee âm → cần ABS để ra số dương
